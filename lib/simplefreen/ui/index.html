What is consolidation?

Each bank profile scrapes its own source and serves a per-profile SimpleFIN URL. Consolidation overlays a second surface on top of those sources: one merged SimpleFIN URL that downstream apps (Actual, Sure.am) can point at instead.

  1. Link. Accounts seen in two or more sources are joined into a group. Auto-linking uses portable identifiers (IBAN-derived); for sources without those, add a manual alias.
  2. Window. For each linked group, pick a primary source and optional per-source date windows so history is split cleanly (e.g. ING from 2025-01-01, Fintonic up to 2024-12-31) with no duplicate transactions.
  3. Serve. Set up the consolidated profile to mint the single SimpleFIN URL. Per-profile URLs keep working in parallel. Use Export preview to verify exactly what the merged URL emits before re-linking clients.

Linked accounts

Accounts that are the same physical bank account, observed across multiple sources. Auto-linked groups are joined by a portable identifier (e.g. IBAN-derived). Aliased groups were linked manually by you.

Consolidated profile

A single SimpleFIN URL that serves the merged view across every source. Per-source date windows let you split history (e.g. ING from 2025-01-01, Fintonic up to 2024-12-31) without complex deduplication. Per-profile URLs keep working in parallel.

Export preview

Exactly what the consolidated SimpleFIN URL is currently emitting to downstream apps (Sure.am, Actual). Use this to verify what gets exported before pointing a client at it.
